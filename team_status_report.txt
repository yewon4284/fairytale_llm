[세이프가드 재보정 작업 - 전체 진행 과정 정리]

■ 0. 문제 상황
카나나 세이프가드가 아동 정보책/전래동화에서 도메인 특화 오탐(S3 성적콘텐츠/S5 아동성착취/S6 자살자해)을 너무 자주 냄. 예: 곤충·동물·식물 정보책(거미/나비/개미/버섯), 배변·위생 교육, 음식안전 교육("함부로 먹지 않아요"), 신체경계 교육("뽀뽀하기 싫어요")이 실제로는 안전한 내용인데 위험 카테고리로 잘못 태깅됨.
게다가 기존 파이프라인은 S3/S5/S6이 태깅되면 Solar 맥락 검토 없이 무조건 UNSAFE로 하드포싱하고 있었음 → 오탐이 그대로 최종 판정까지 이어짐.

■ 1. 하드포싱 제거 (구조적 수정)
- evaluator.py 프롬프트 개정: S3/S5/S6 태깅돼도 "그대로 믿지 말고 맥락으로 재검토"하도록 지시 추가, 도메인 오탐 유형(곤충/배변위생/음식안전/신체경계) 예시까지 명시
- 하드카테고리 강제 로직 완전히 삭제 (팀 방침: 이건 무조건 없애야 한다는 결정)

■ 2. 세이프가드 자체 재보정 (LoRA 파인튜닝) 시도
- 재보정 데이터셋 구축
  - build_calibration_dataset.py: 기존 FP/TP 케이스에서 문장 추출, 758개 (순환신호 버그 발견해서 수정 — TP 레코드는 검증된 카테고리만 쓰도록 고침)
  - mine_domain_safe_examples.py: 곤충/배변위생/음식안전/신체경계 키워드로 안전 문장 127개 추가 마이닝 (self-merge 버그 있었음, 수정)
  - 최종 871개 (SAFE 605 / S5 179 / S3 69 / S6 18) + 장서연 팀원 s5_dataset.json 214개 병합
- 장서연님이 paper_jsy 브랜치에서 실험한 과적합 방지 하이퍼파라미터(epoch 3, lr 5e-5, dropout 0.1, val_ratio 0.15, EarlyStopping) 가져와서 train_s5.py에 반영
- 학습 중 환경 문제 다수 (torch/CUDA 버전, trl API 변경, transformers 자동업그레이드로 인한 버그 등) 해결하며 최종 학습 완료 — eval_loss 0.43대, 어댑터 저장 완료

■ 3. 실패한 대안: 문맥 윈도우 방식
문장 단독 분류 대신 앞뒤 문맥 포함해서 분류하는 방법도 테스트해봄. 오탐은 82% 해소됐지만 진짜 위험한 케이스(정탐) 63%를 놓치는 심각한 재현율 손실 발견 → 프로덕션 적용 안 하기로 하고 폐기 (실패 원인은 코드에 문서화해둠)

■ 4. 재보정 어댑터 검증 — 1차 시도 (순환적 테스트)
같은 데이터로 만든 어댑터를 비슷한 데이터로 테스트해서 "FP 23건 해소 / TP 2건 손실"이라는 고무적인 결과가 나왔었는데, 이건 세이프가드 1차 분류 단계만 본 거고 학습 데이터와 겹치는 부분이 있어 순환 오염 우려 있음 → 진짜 검증 아님

■ 5. 진짜 검증 — 441편 전체 파이프라인 재평가
all_data 441편 전체를 현재 파이프라인(세이프가드+Solar)으로 재실행, 사람이 라벨링한 kanana_solar_eval.jsonl(421편, ground_truth 포함)과 비교하는 스크립트(compare_calibrated_run.py) 작성

- 1차 비교(구 baseline과 비교): 재현율이 91.4%→70.6%로 폭락한 것처럼 보여서 "이거 문제 있다" 판단했었음
- 근데 진단해보니 이 비교는 하드포싱 제거 + 프롬프트 개정 + 어댑터가 다 섞여있는 비교였음 (baseline이 구 하드포싱 파이프라인 결과였음)
- 그래서 스크립트에 통제 비교 모드 추가 → 같은 현재 코드로 어댑터만 있고/없고 따로 441편씩 두 번 실행해서 비교

■ 6. 최종 결론 (통제 비교로 원인 분리 완료)
[재보정 어댑터 단독 효과 — 421편, 어댑터 유무만 다르고 나머지 코드 동일]
  정확도 53.9%→55.8% (+1.9pt) / 정밀도 50.6%→52.1% (+1.5pt) / 재현율 69.5%→70.6% (+1.0pt) / F1 58.6%→59.9% (+1.4pt)
  → 전 지표 소폭 개선이지만 McNemar p=0.40으로 통계적 유의미성은 없음. 해롭진 않다는 정도는 확인.

[하드포싱 제거의 효과 — 이게 진짜 임팩트 있는 변화였음]
  특이도(SAFE 정답률) 19.6%→40.2% (두 배), FPR(오탐율) 80.4%→59.8% 개선
  대신 재현율 91.4%→69.5%로 하락 — 지난번 "재현율 폭락"은 사실 이거였음, 어댑터 탓 아니었음

[여전히 안 풀린 문제]
  - 원래 목표였던 도메인 오탐 44건 중 17건(38.6%)만 해소 — 방귀 시합/곤충류 등 타겟 예시 상당수 아직도 UNSAFE
  - 재현율 69~71% 자체가 낮음 (위험한 동화 10개 중 3개꼴로 놓침) — 어댑터 문제가 아니라 Solar 2차 평가 로직을 더 봐야 할 문제
